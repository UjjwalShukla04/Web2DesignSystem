# Frontend

Next.js app for the Website → React Component Generator. The whole UI lives in `app/page.tsx`.

```bash
npm install
npm run dev     # http://localhost:3000
```

Set `NEXT_PUBLIC_API_URL` (e.g. in `.env.local`) to point at the backend; it defaults to `http://localhost:4000`.

See the [project README](../README.md) for full setup and [archReadme.md](../archReadme.md) for how it works.
