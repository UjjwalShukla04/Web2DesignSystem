# Website → React Component Generator

Paste a website URL, pick a section of the page, and get an editable, **Tailwind CSS**-styled component generated by AI, with a live preview and a chat box for refining it.

- **Output formats:** React, Vue, Svelte or plain HTML (⚙ Settings → Output).
- **Whole pages:** pick up to 8 sections with the **+** buttons and generate one page with a shared color and font palette.
- **Matches the look:** the AI also gets a screenshot of each section (can be turned off in ⚙ Settings), and the editor's **Compare** view shows the original next to the live preview.
- **Real device widths:** preview at phone (390px), fit, or desktop (1280px, scaled to fit) width.
- **Long output:** if the AI hits its output limit, it's asked to continue where it stopped.
- **History:** everything you generate is saved in your browser (IndexedDB), including manual edits; reopen it any time from the 🕘 History drawer.
- **Costs & limits:** each AI request shows its estimated cost; the server's keys have a per-user daily limit and an optional daily budget.
- **Light / dark / system theme** (🌙 button) and a **phone layout** (Code / Preview / Original tabs).
- **Export:** download the code file (and `fonts.css` with the original site's web fonts), copy it, or open it in CodeSandbox.
- **Fast re-opens:** a page scraped in the last 10 minutes is reused instantly (**Refresh** scrapes it again).

- **Frontend**: Next.js 16 + Sandpack live editor (`frontend/`)
- **Backend**: Express + Playwright scraper + Gemini/OpenAI (`backend/`)

How it works in detail: [archReadme.md](archReadme.md). Deploying to Render + Vercel: [deployment.md](deployment.md).

## Local Setup

Requirements: Node.js 24 (see `.nvmrc`).

### 1. Backend

```bash
cd backend
npm install        # also downloads Chromium for Playwright (postinstall)
```

Copy `backend/.env.example` to `backend/.env` and add at least one AI key:

```env
GEMINI_API_KEY=your-gemini-key   # Gemini (default provider)
OPENAI_API_KEY=sk-...            # OpenAI (chosen in the app's settings)
```

`.env.example` lists every other setting.

```bash
npm run dev        # http://localhost:4000, restarts on changes
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev        # http://localhost:3000
```

The frontend calls `http://localhost:4000` by default. To use another backend, set `NEXT_PUBLIC_API_URL` in `frontend/.env.local`.

In the app, ⚙️ **Settings** has:

- **Provider**: Gemini or OpenAI.
- **Gemini API Key** and **OpenAI API Key**: optional keys of your own, one per provider. The key of the selected provider is used; each field says whether the server already has a key for that provider. They're kept in the browser tab only (cleared when it closes).
- **Server Access Code**: needed for scraping if the backend has `API_SECRET` set.

## Configuration (backend)

| Variable | Default | Purpose |
|---|---|---|
| `GEMINI_API_KEY` | – | Gemini key (default provider). Without it, a placeholder component is returned. |
| `OPENAI_API_KEY` | – | OpenAI key, used when the user picks OpenAI. |
| `API_SECRET` | – | Access code required by the API. **Required in production** (the server won't start without it) unless `ALLOW_OPEN_ACCESS=true`. |
| `ALLOW_OPEN_ACCESS` | – | Set to `true` to deliberately run a public API in production without `API_SECRET`. |
| `ALLOWED_ORIGINS` | all origins (dev only) | Comma-separated frontend URLs allowed by CORS, or `*` for any. **Required in production.** |
| `GEMINI_MODEL` | `gemini-flash-latest` | Gemini model name. |
| `OPENAI_MODEL` | `gpt-4o` | OpenAI model name. |
| `TRUST_PROXY` | `1` | Number of reverse proxies in front of the server (for per-IP rate limits). |
| `MAX_CONCURRENT_SCRAPES` | `1` | Pages scraped at once; 5 more can queue. |
| `SCRAPE_TIMEOUT_MS` | `90000` | Hard time limit for one scrape (504 after that). |
| `SCRAPE_CACHE_TTL_MS` | `600000` | How long a scrape result is reused for the same URL (10 min). `0` disables the cache. |
| `SCRAPE_CACHE_MAX_ENTRIES` | `10` | Most scrape results kept in memory. |
| `DAILY_GENERATIONS_PER_USER` | `50` | Generations per user (IP) per day with the server's key. `0` = unlimited. Users with their own key aren't limited. |
| `DAILY_BUDGET_USD` | `0` (off) | Estimated USD the server's keys may spend per day, all users together. |
| `GEMINI_PRICE_INPUT` / `_OUTPUT`, `OPENAI_PRICE_INPUT` / `_OUTPUT` | `0.3`/`2.5`, `2.5`/`10` | USD per 1M tokens, for cost estimates. Update if prices or models change. |
| `LOG_FILE` | `server.log` (dev), off (production) | Log file, in addition to the console. `off` disables it. |
| `PORT` | `4000` | HTTP port. |

"Production" means `NODE_ENV=production` or running on Render (`RENDER=true`).

## Scripts

| Where | Command | What it does |
|---|---|---|
| backend | `npm run dev` | Run with auto-reload (tsx + nodemon) |

GitHub Actions (`.github/workflows/ci.yml`) runs all of these on every push and pull request.

## API at a Glance

| Endpoint | Purpose |
|---|---|
| `POST /api/scrape` `{ url, fresh? }` | Returns the page's detected sections (`fresh: true` skips the cache) |
| `POST /api/generate` `{ html, format?, instructions?, provider?, apiKey?, fonts? }` | Generates a component from a section (`format`: `react`, `vue`, `svelte`, `html`) |
| `POST /api/generate` `{ sections: [...], ... }` | Combines 2–8 sections into one page |
| `POST /api/generate` `{ currentCode, instructions, ... }` | Applies a change to an existing component |
| … with `"stream": true` | Streams the AI's output as newline-delimited JSON events |
| `GET /api/usage` | Your AI usage today with the server's key, and the limits (public; only your own numbers) |
| `GET /api/providers` | Which AI providers have a key on the server, e.g. `{ "gemini": true, "openai": false }` (public; never returns keys) |
| `GET /health/browser` | Checks that the headless browser can start |

Full request/response details, limits and error codes: [archReadme.md § API Reference](archReadme.md#4-api-reference).
